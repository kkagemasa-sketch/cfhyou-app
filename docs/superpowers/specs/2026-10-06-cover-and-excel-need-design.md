# PDF表紙の作り直し＋必要保障額のPDF・Excel表示＋Excelの折り返しをなくす（設計書）

作成日：2026-10-06　／　対象：CF表アプリ（feature/mg-reorg ＝ 本番 v619 と同じ状態から）

## 1. 決めたこと（ユーザー承認済み）

| 項目 | 決定 |
|---|---|
| 表紙のデザイン | 案A-1（左に紺の帯・右に内容）。通常時・万が一とも同じ形 |
| ロゴ | 白い箱なし。ロゴを白一色にして左帯の上に置く |
| 前提条件 | 右側の大きな枠1つにまとめ、数字を大きく。段＝自己資金の内訳／住宅ローン条件／（買い替え予定があれば）／その他金融資産＋注釈・補足メモ |
| 万が一の表紙 | 右上に必要保障額の3枚カード（安心だけ紺で大きく）＋色枠の説明、下に前提条件（通常より少し小さい文字）。帯に「○○様が△歳で死亡（障害1級／2級）した場合」と、その年・家族の年齢 |
| 種類の色 | 帯の右端の線・見出しの印＝万が一の種類の色（死亡 #c2185b／障害1級 #3459ca／障害2級 #159ea3）。通常時は #2bb3a3 |
| Excelの必要保障額 | 4行（見出し／金額／根拠の年／考え方）×3つの枠（年の列を3等分）＋色枠の説明1行。総金融資産の根拠のマスを画面と同じ色の太枠で囲む |
| Excelの折り返し | CF表シート全体（通常・万が一）で折り返しをなくす。情報欄は項目ごとに文字幅を測って必要な列数だけ結合、入りきらなければ次の行へ。行の高さは1行分に。ご確認事項シートの文章と注釈メモの改行はそのまま |

見本：同じフォルダの ncover2_A1.png（通常）・mgcover2_M.png（万が一）・mock_excel.png（Excel）、デザインの元HTML mock_cover_n2.html・mock_cover_mg2.html。

## 2. 作り

### 2-1 表紙のデータ（新規 js/cover.js）
- `getCoverData(kind, mgCtx)` が表紙に載せる値を1か所で作る（画面の cf-table.js の上部サマリーと同じ計算）。
  - 共通：お客様名、戸建て／マンション、ローンの形（単独／ペア／連帯／フラット35／現金一括）、期間（開始〜終了年・年数）、家族の年齢（ご主人様・奥様・お子様）、作成日、担当
  - 自己資金の内訳：現預金合計 → 頭金（自己資金／贈与／その他）・諸費用（現金／ローン組込／その他）→ 購入後残高、引越・家具家電の注記
  - 住宅ローン条件：住宅価格・引き渡し年＋借入額・金利（変動/固定の別）・返済期間を、単独は1行・ペアは2行。現金一括購入は「ローンなし」
  - その他金融資産（現時点）：項目ごと＋合計（画面と同じ集計）
  - 買い替え・住み替え予定（ある場合のみ）
  - 注釈・補足メモ（改行を保つ）
  - 万が一：見出し文（例：ご主人様が32歳で死亡した場合）、その年と家族の年齢、種類の色、必要保障額（MR.need の最低限・標準・安心、根拠の年と年齢、標準の年数）
- 単身世帯は「ご本人」表記・奥様欄なし。

### 2-2 PDF表紙（js/print.js の _ppBuild）
- 今の「表紙（ヒーロー＋前提条件の複製）」を、`getCoverData` から組み立てる A-1 の表紙に置き換える。
- 万が一を複数タブまとめて印刷するときは、タブごとに切り替えて計算した値でそれぞれの表紙を作る（openPrintPreviewMG で各タブの cover データも写し取る）。
- 1ページに収まらないとき（ペア＋買い替え＋長いメモ等）は、右側の文字を段階的に小さくして収める（ご確認事項と同じ方式）。
- CSS は css/style.css に pp-cover2 系のクラスで追加（印刷・画面プレビュー共通）。今の pp-cover 系は使わなくなるが、削除はしない（削除は別途ユーザー確認）。

### 2-3 Excel（js/export.js）
- 必要保障額：今の1行（info）を、4行×3枠＋説明1行に置き換える（行の型 'need'）。枠の色・太字・金額の大きさは画面に合わせる。
- 根拠のマス：総金融資産の行で MR.need.iMin（最低限が0より大きいとき）／iStd／iSafe の列のセルに、画面と同じ色の太い枠（medium）。
- 情報欄（通常・万が一とも）：今の「1項目＝3列固定」をやめ、項目ごとに文字幅（全角2・半角1、フォント9pt基準）から必要な列数を求めて結合する。表の幅を超える分は次の行へ送る。wrapText をやめ、行の高さを1行分（18pt前後）にする。
- そのほかCF表シートで wrapText を使っている所も1行表示にする（注釈メモ・残高警告の行は改行位置だけ保つ）。
- ご確認事項シートは変えない。

## 3. テスト
- print-test：通常・万が一（死亡／障害）・ペア／単独／現金一括・買い替えあり・長いメモで、表紙が1ページに収まる／カードの金額が画面（MR.need）と一致／前提条件の数字が画面のサマリーと一致。
- Excel（mgtab-test に追加）：必要保障額の3つの金額が MR.need と一致、根拠のマスに色枠、CF表シートに wrapText のセルがない（注釈・警告を除く）、情報欄の各項目の文字幅が結合幅に収まる。
- 既存の自動チェック一式（calc／mode／diff-excel／print／lctab／mgtab）が合格。計算結果は変えない。

- すべて合格・ユーザーが確認用画面で確認後、版を上げてまとめて本番へ。
